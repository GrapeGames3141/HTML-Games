# Motunui procedural island

Open `procedural-demo.html` in a current WebGL 2 browser. It is a standalone procedural scene with no downloads or third-party libraries.

Drag to orbit. Use the mouse wheel or a two-finger pinch to change the camera distance. Aerial, Strand, and Reef select art-directed views. Keys `1` through `3` choose those views and `R` restores Aerial.

The scene generates its island mesh, bathymetry, ocean, cloud field, canopy atlas, vegetation, palms, and terrain shadow texture in the browser from a fixed seed.
