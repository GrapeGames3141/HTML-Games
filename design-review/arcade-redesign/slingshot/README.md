# Slingshot arcade card

`slingshot-raw.png` is an actual local headless capture from `slingshot/slingshot.html?test&seed=7&q=high&desktop`. The test API started the first target range, solved and aimed at a can, then held the draw. HUD elements were hidden only in the capture browser. No generated or repainted artwork was used.

`assets/arcade/slingshot.webp` is the reviewed 800×560 crop of that 1200×840 source frame.
